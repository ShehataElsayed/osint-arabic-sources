# دليل المصادر المفتوحة للصحفيين العرب

دفعة أساس قابلة للنشر بعد مراجعة التغييرات. تحافظ على الموقع العربي والتصميم وخط Cairo ونسبة العمل لشحاتة السيد.

## البناء والاختبار

يتطلب Node.js 22 وPython 3.12 أو إصدارًا متوافقًا.

```sh
npm ci
npm run build
npm test
npm run check:js
python3 -m http.server 8000 --directory _site
```

المصدر في `site/`، وبيانات الخريطة والمكتبات وأدوات الذكاء الاصطناعي في `data/` والخريطة في `2-data.json`.
ينشئ البناء صفحات التصنيفات وفهرس Pagefind داخل `_site/`.
لا تستخدم ملفات ZIP كمدخل للنشر. ملف الإدارة المشفر محفوظ كما هو.

## جودة الروابط

`3-review-queue.json` سجل انتظار مراجعة، وليس شهادة بأن الروابط تعمل.
تاريخ آخر فحص غير معروف لكل الروابط حاليًا. لا تعني حالة `live` الموروثة فحصًا حديثًا.
تظهر الأداة في أكثر من فرع عند الحاجة؛ 1168 إدخالًا لا تعني 1168 أداة مستقلة.

## حدود الاختبارات الحالية

الاختبارات البنيوية لا تثبت جودة البحث الدلالي أو صحة الأدلة. تشغيل Python وR
والنماذج يتطلب تنزيل مكتبات من خدمات خارجية. النسخة ليست بلا اتصال بالكامل.
لا تُرفع بيانات تحقيق حساسة إلى خدمة خارجية دون مراجعة السياسة والحقوق.

التغييرات المقترحة: بناء ثابت من ملفات المصدر، اختبارات أساسية، وسجل مراجعة،
مع إظهار NewsRAG في التنقل واستعادة الشعار وقائمة الأقسام في صفحته.
العمل متاح ضمن نطاق الرخصة الحالية، مع بقاء إشعارات الطرف الثالث.
