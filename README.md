# دليل المصادر المفتوحة للصحفيين العرب

دليل عربي تفاعلي لأدوات ومصادر البحث مفتوح المصدر (OSINT)، مع أدوات مساعدة للتحقق: خريطة مصادر، أوامر بحث استقصائية، بحث ذكي داخل الدليل، وتجربة تحقق تعرض كل نتيجة مع أسبابها وحدودها.

**الموقع:** https://shehataelsayed.github.io/osint-arabic-sources/
**تجربة التحقق:** https://shehataelsayed.github.io/osint-arabic-sources/rag.html

## كيف تعمل أداة التحقق

الأداة لا تعطي حكمًا نهائيًا ولا تقول إن شيئًا "تم التحقق منه". تعرض إجابة وتقدير ثقة، وتشرح سببه.

1. تُسأل خدمة ذكاء اصطناعي خارجية عن الادعاء ثلاث مرات، ثم تُسأل سؤالًا رابعًا لنقد الإجابة. يُرسل نص الادعاء وحده، وتظهر في الصفحة عبارة تنبه المستخدم إلى ذلك.
2. تُفتح فعلًا كل الصفحات التي ذكرها النموذج. الرابط الذي لا يُفتح يظهر على أنه لم يُفتح، ولا يُنسب إليه مقتطف.
3. إن فشل رابط، يُبحث عن صفحة حقيقية على النطاق نفسه (خريطة الموقع أولًا، ثم بحث مقيّد بالنطاق)، ولا يُعرض إلا ما فُتح فعلًا، مع وسم "رابط بديل من نفس النطاق" والرابط الأصلي.
4. يبحث الخادم أيضًا في الويب عن صفحات للادعاء نفسه، وتمر بالفحوص نفسها، وتظهر موسومة بأنها وُجدت بالبحث لا من النموذج.
5. تُقارن جمل الصفحة المفتوحة بالادعاء، وتُطابق الأرقام. تُعدّ الصفحة داعمة إن بلغ التشابه 0.4 على جملة من 6 كلمات أو أكثر وطابقت الأرقام. ما يُعرض مقتطف حرفي من الصفحة، لا من كتابة النموذج.
6. تُعرض لكل مصدر فئته (رسمي، إخباري، أكاديمي، غير معروف) وبيانات الهوية المتاحة (عمر النطاق، الجهة المسجِّلة، HTTPS، صفحات "من نحن" و"اتصل بنا")، وحقول غير المتاح تظهر "غير متاح".
7. مستوى الثقة: **منخفض** إن فشل أي معيار، **متوسط** في الباقي، و**مرتفع** فقط حين تُفتح صفحة من فئة رسمية أو إخبارية أو أكاديمية وتجتاز الفحص. فئة المصدر وحدها لا ترفع الثقة.

![مصادر مفتوحة وروابط بديلة](docs/images/rag-sources.png)

التفاصيل: [docs/how-verification-works.md](docs/how-verification-works.md).

### حدود صريحة

- الأداة لم تُقيَّم على مجموعة ادعاءات معروفة الحقيقة، ولا ينطبق عليها أي رقم دقة. أرقام مكتبة NewsRAG الأصلية (84.1 و93.2) تخص تلك المكتبة وليست هذه الأداة.
- معرفة النموذج ليست دليلًا. الدليل هو ما وُجد في صفحة مفتوحة ومرّ بالفحص.
- حصة الخدمة المجانية محدودة؛ تظهر عبارة "الخدمة مشغولة" عند نفادها.
- مؤشر `validated_for_release` يبقى `false` في الشيفرة والوثائق.
- لا يُنسخ نص من AFP أو مصبار أو "عرب فاكتس". عناصر تدقيق الحقائق مقتطف قصير مع الرابط.

## بنية المستودع

```text
site/        مصدر الموقع (HTML وJS وCSS)
data/        مكتبات التحليل وأدوات الذكاء الاصطناعي
2-data.json  خريطة المصادر والتصنيفات
worker/      خادم Cloudflare Worker لوضع التحقق والترشيح
scripts/     بناء الموقع وفهرس البحث وفهرس تدقيق الحقائق
tests/       اختبارات بايثون وNode ومتصفح
docs/        الشروحات والعقود
.github/     النشر والقوالب
```

شرح أوسع: [docs/structure.md](docs/structure.md).

## التشغيل المحلي

يتطلب Node.js 22 وPython 3.12 أو أحدث.

```sh
npm ci
npm run build          # ينشئ _site وفهرس Pagefind
npm test               # اختبارات بايثون وNode
npm run check:js       # فحص صياغة الشيفرة
python3 -m http.server 8000 --directory _site
```

لا يدخل أي ملف ZIP في البناء. ملفات ZIP في الجذر نسخ أرشيفية قديمة.

## النشر

يُنشر الموقع على GitHub Pages تلقائيًا عند الدمج في `main` عبر `.github/workflows/deploy.yml`. أما الـ Worker فيُنشر بشكل منفصل. الخطوات والأسرار المطلوبة في [docs/deployment.md](docs/deployment.md).

## جودة الروابط

`3-review-queue.json` سجل انتظار مراجعة، وليس شهادة بأن الروابط تعمل. تاريخ آخر فحص غير معروف لمعظم الروابط، ولا تعني حالة `live` الموروثة فحصًا حديثًا. تظهر الأداة الواحدة في أكثر من فرع، فلا يعني العدد الإجمالي للإدخالات عدد الأدوات المستقلة.
