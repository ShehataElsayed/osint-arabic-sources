## ما يعنيه هذا لتغيير الرخصة

- الترخيص الشامل (blanket relicense) لا يغيّر رخص المواد أعلاه. المشتق من OSINT Framework يبقى MIT، وفهرس تدقيق الحقائق يبقى CC BY-NC-SA 4.0 (غير تجاري)، والخط يبقى OFL.
- إن أُريدت رخصة Apache 2.0، فالمنطقي أن تشمل الشيفرة الأصلية فقط (`worker/` و`scripts/` و`tests/` وشيفرة `site/` المكتوبة حديثًا). وهي رخصة برمجيات؛ لا تناسب النصوص العربية والتحرير، التي تناسبها رخص المشاع الإبداعي مثل CC BY-SA 4.0 الحالية.
- لا توجد رخصة باسم Apache 2.5. أحدث إصدار هو Apache License 2.0.
- أي رخصة جديدة لا تنفذ دون موافقة المالك الصريحة على الرخصة ونطاقها.
